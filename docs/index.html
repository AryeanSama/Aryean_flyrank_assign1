0. Abstract

Can historical traffic volatility predict page-level search performance decay 30 days in advance? Using DuckDB over FlyRank search performance data, we constructed a 60-day temporal lookback matrix targeting page decay. A LightGBM classifier was evaluated using a time-aware out-of-time test split against a historical heuristic baseline. The final model achieved an ROC-AUC of 0.812 (+39.5% lift) and a Precision @ Top 10% of 0.684 against an 18.5% decay base rate. This system outputs a 4-tier risk score to prioritize manual editorial content refreshes.

1. Problem Framing

Decision Supported: Prioritizes underperforming pages for content updates and search intent re-alignment before traffic loss compounds.

Unit of Analysis: Page-level aggregates evaluated across 30-day rolling windows.

Output: 4-tier risk score (0.00 to 1.00 decay probability).

Human Action: Editorial teams review Tier 1 flagged pages to update outdated statistics, refresh metadata, or re-align search intent.

Cost of Error: False Positives waste editorial labor on stable pages; False Negatives cause unmitigated traffic loss over extended timeframes. ML provides scalable, automated rank-order prioritization across thousands of URLs.

2. Data Safety

Data ingested via DuckDB from hf://datasets/flyrank/ml_internship_warehouse/*.parquet. Pages under 50 monthly impressions were excluded. Label-derived leakage fields (e.g., trend_direction, trend_pct) were deliberately dropped prior to training. All client identifiers, domains, and queries were hashed into pseudonymous page IDs used strictly for grouping, never as features. No private details appear in work/.

3. Baseline

Rule Baseline: Flags a page for decay ($1$) if recent 7-day average traffic drops below the prior 30-day average (impression_slope_7_30 < 1.0). Evaluated on the exact same test split, the baseline yielded an ROC-AUC of 0.582 and Precision @ Top 10% of 0.423.

4. Model / Analysis

Method: LightGBM Classifier (100 estimators, max depth 3). Fits non-linear feature interactions without overfitting noisy time-series data.

Features Included: impression_slope_7_30, ctr_volatility_14d, position_drift_delta.

Features Excluded: Target-derived fields and pseudonymous page IDs.

Target Definition: Binary flag ($Y=1$) if page traffic drops by ≥20% in the evaluation window ($T$ to $T+30$).

5. Evaluation

Split Design: Time-Aware Out-of-Time Split (Train: Months 1–4; Test: Months 5–6) to eliminate temporal data leakage.

Model Architecture Precision @ Top 10% ROC-AUC F1 Score
Historical Heuristic (Baseline) 0.423 0.582 0.461
LightGBM Classifier (Final) 0.684 0.812 0.729

Base Rate: Decay majority class base rate is 18.5%. Model precision of 0.684 at Top 10% represents a 3.7x lift over random guessing.

Error Analysis: False Positives occur on pages experiencing short-term seasonal volatility; False Negatives occur on low-volatility pages facing sudden competitor keyword launches.

6. Interpretation

Feature importance analysis shows impression_slope_7_30 (52% weight) and position_drift_delta (31% weight) drive the majority of decay predictions. Stable historical trajectories were observed as the strongest directional indicators of future performance resilience.

7. Recommendation

  • Tier 1 (Risk > 0.80) — High Priority Refresh: Immediate editorial rewrite within 7 days.
  • Tier 2 (Risk 0.55–0.79) — Metadata Optimization: Re-optimize title tags, headers, and meta descriptions within 14 days.
  • Tier 3 (Risk 0.35–0.54) — Automated Monitoring: Retain on weekly tracking list.
  • Tier 4 (Risk < 0.35) — Maintain: Healthy asset; no action required.
